# Noir & Marée — prototype

Prototype de site vitrine premium pour une agence web à Andernos-les-Bains.

## Stack
- HTML5
- CSS3
- JavaScript vanilla
- SVG inline pour le logo
- Aucun framework obligatoire
- Aucun hébergement propriétaire

## Mise en ligne
Le site est prêt pour GitHub Pages, Cloudflare Pages ou n'importe quel hébergement statique.

## Vidéo d'arrière-plan
Le hero utilise actuellement une animation CSS abstraite afin que le prototype fonctionne immédiatement sans dépendance vidéo.
Pour ajouter une vidéo locale, déposer un fichier `assets/video/hero.mp4` et remplacer le contenu `.hero-video` dans `index.html` par une balise `<video autoplay muted loop playsinline>`.
Prévoir une image `poster` et un fallback CSS pour les connexions lentes.
